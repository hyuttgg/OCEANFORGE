# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in OceanForge Desktop, please report it responsibly:

1. **Do NOT** open a public GitHub issue.
2. Email the maintainer directly or use GitHub's private vulnerability reporting.
3. Include: description, reproduction steps, impact assessment.
4. We will acknowledge within 48 hours and provide a fix timeline.

## Scope

- OceanForge Desktop application
- OceanForge API backend
- Authentication flows (Google/Discord OAuth)
- Key generation and validation
- Update/launcher mechanisms

## Out of Scope

- Roblox platform vulnerabilities
- Third-party service outages
- Social engineering attacks
